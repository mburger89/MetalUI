## 1 What exists and what is missing

`ImageInfo(data:)`/`(contentsOfFile:)` (record 117) reads a PNG IHDR or a JPEG SOF and is `nil` for everything else:
GIF, TIFF, BMP, WebP, HEIF and AVIF as for garbage and as for a damaged PNG. A caller cannot say "unsupported type"
versus "damaged" versus "not a picture". MetalCreator keeps `OtherPictureSignature` (seven prefixes, about 15 lines) for
it and will delete it. `ImageHeader.swift` already has `HeaderSource`, `MemoryHeaderSource`, `FileHeaderSource` (regular
files only, 64 KiB window, `HeaderTrace` counters) and the PNG/JPEG signatures inside `readImageInfo`.

## 2 Public API (class `M`)

```swift
public enum ImageFileFormat: Sendable, Hashable, CaseIterable {
    case png, jpeg, gif, tiff, bmp, webp, heif, avif, unknown
}
extension ImageInfo {
    public static func sniffedFormat(of data: Data) -> ImageFileFormat
    public static func sniffedFormat(ofFile path: String) -> ImageFileFormat
}
```
Doc comments state `IS-C`: a sniff names a prefix; `.png`/`.jpeg` with a `nil` `ImageInfo` is damaged, another case
with `nil` is unsupported, `.unknown` is not a picture; exhaustive switches need a `default` as cases may be added (`IS-A`).

## 3 Behaviour

Signatures per `IS-D` (PNG 8 bytes, JPEG 3, GIF 6, TIFF 4 both orders, BMP 18 with DIB size, WebP 12, `ftyp` brands 12).
A prefix one byte short of a signature is `.unknown`; empty and garbage are `.unknown`; bytes past the signature are
never read; one read of `min(size, 18)` bytes at offset 0. The file form: missing path, directory, FIFO, device and an
unreadable file are `.unknown` (`IS-F`); the answer equals the data form of the whole file.

## 5 Tests (`ImageSniffTests`, each value test red on arrival: the symbol does not exist, so the file fails to compile)

Helper `minimalPrefix(for: ImageFileFormat) -> [UInt8]` (shortest matching bytes per `IS-D`); every test iterates
`ImageFileFormat.allCases` minus `.unknown` so a case without an arm fails.

1. `everyFormatsMinimalSignatureSniffsItsCase`: PNG, JPEG, GIF87a, GIF89a, both TIFF orders, BMP (DIB 40), WebP, each HEIF
   brand (8), each AVIF brand (2). Mutation: delete/alter each signature arm in turn (PNG, JPEG, GIF87a, GIF89a, TIFF LE,
   TIFF BE, BMP, WebP, HEIF, AVIF; the case's own sub-test must redden, name them).
2. `everyTruncatedByOnePrefixSniffsUnknown`: each minimal prefix minus its last byte (and every shorter prefix down to
   empty) is `.unknown`. Mutation: weaken a length guard (`count >= n-1`), PNG and WebP arms.
3. `emptyAndGarbageSniffUnknown`: empty, one byte, text `"hello world, this is text"`, `BM` + text (BMP's second witness),
   `RIFF....WAVE`, BigTIFF `II 2B 00`, an `ftyp` with brand `isom`, 1 KiB of zeros. Mutation: drop the DIB-size check (BMP-text
   case reddens), drop the `WEBP` tag check (WAVE case), widen the brand set to include `isom`.
4. `aDamagedPNGSniffsPNGWhileImageInfoIsNil`: valid PNG with one IHDR CRC byte flipped: sniff `.png`, `ImageInfo(data:)` nil;
   same for a JPEG with no SOF; a GIF/WebP sniffs its case while `ImageInfo` is nil (the three-way answer, `IS-C`).
   Mutation: make `sniffImageFormat` call `readImageInfo` and return `.unknown` on nil.
5. `sniffReadsOnlyThePrefix`: a `HeaderSource` spy over 1 MiB records reads: exactly one read at offset 0 of `min(size, 18)`
   bytes; short sources do not read past `size`. Mutation: read 64 bytes, or read twice.
6. `theFileFormAgreesWithTheDataFormAndRefusesWhatIsNotARegularFile`: temp files of every case, `.unknown` for a directory, a
   missing path, an empty file, a symlink to a file agrees, a symlink to a directory is `.unknown` (symlink cases `#if !os(Windows)`, `IS-J`); a `nil` read from a spy source is `.unknown`; with a `HeaderTrace`
   (package seam): one refill at 0, `payloadReads == 0`, `wholeFileLoads == 0`. Mutation: use `Data(contentsOf:)` (trace
   pin), drop the regular-file check by reading through `FileHandle` directly (directory case).
7. `sniffNeverTrapsOnAnySingleByteMutationOfAValidSignature`: each byte of each minimal prefix set to 0x00 and 0xFF stays in
   `allCases` without trapping (and equals `.unknown` unless another signature matches, computed by an independent oracle in
   the test). Mutation: an unchecked index at 12.
8. `sniffAndImageInfoAgreeOnPNGAndJPEGFixtures`: every valid PNG/JPEG builder `ImageInfoTests` uses sniffs the case of
   `ImageInfo.format`. Mutation: swap the PNG and JPEG arms.
9. `iterationCoversNineCases`: `ImageFileFormat.allCases.count == 9` with `try #require`; a tenth case needs a test arm.
10. **Guard `G-IS1`** (`Tests/MetalUITests`, `typecheckFile`, plain import): the enum, its cases and the two statics
    compile; `HeaderSource` and `sniffImageFormat` do not (separating controls, one fixture each). Mutation, run red once:
    make `sniffImageFormat` `public`.

Every mutation is run on the committed tree, restored from a copy, full unfiltered suite, `git status --short` after, the
reddened tests named. Expected count change: +9 tests, +1 guard (4060 -> 4069, 249 -> 250 typecheck guards), re-measured.
