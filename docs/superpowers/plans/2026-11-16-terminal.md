# Terminal (Alloy gaps 1-5) - phased plan

Spec (binding, all signatures): `docs/superpowers/specs/2026-11-16-terminal-design.md`. Rulings: `docs/superpowers/2026-11-16-terminal-decisions.md` (`TRM-`). Each phase is a set of small PRs that merge on their own; each PR adds its record (`docs/record/NN-*.md`) and its one-or-two-sentence rules to `docs/rules/terminal.md` (key capture also to `input-focus.md`, surface redraw to `drawing.md`). Every new public declaration owes a closeout inventory map row and a doc comment. Divergence labels 1095-1104 are reserved; none expected.

Phases 1, 2, 3 and 4 are independent and may run in parallel. Phase 5 needs 1, 3 and 4. Phase 6 is last.

## Phase 0 - docs and freeze (1 PR)

Spec, decisions doc, plan, prefix row, rules shard, label reservation, record 334. **Proves:** Alloy can write its fakes and its `PtySpawner` against frozen shapes (gaps 1, 3, 4); drafts for 2 and 5 are visible.

## Phase 1 - emulator core (`MetalUITerminal`; pure, runs on all three OSes)

- **1.1 Target and storage.** Target and product, in the non-Apple list; compact rows, scrollback ring, copy-on-write `TerminalRow`. Proves the 4 MB budget by a counted byte census.
- **1.2 Parser.** In-house, from the ECMA-48 and DEC descriptions. Proves chunk-split invariance and fuzz safety.
- **1.3 Screen semantics.** Cursor, erase, insert/delete, scroll regions, tabs, save/restore, alternate screen, graphics set, wide and combining, pending wrap, SGR in all forms, replies. Proves the first conformance batches.
- **1.4 OSC/DCS/APC and snapshots.** OSC 0/2/7/8/10/11, payload and title caps, events, snapshot publish with damage and sharing, `TerminalSnapshotSource` merge. Proves damage and sharing by identity; a 10 MB flood costs one merge per take.
- **1.5 Resize and reflow** of the primary screen. Proves cursor tracking and wide characters at the edge; reflow round trips.
- **1.6 Selection and text.** Linear and block selection, `selectedText`, `search`, `rowText`, viewport offset.
- **1.7 Encoders.** Key tables, mouse encodings, paste stripping, focus. Proves every byte by table rows that fail when one moves.

## Phase 2 - `PseudoTerminal` (parallel with 1)

- **2.1 POSIX spawn spike.** `posix_spawn` with `POSIX_SPAWN_SETSID` first; fork fallback only if macOS refuses the controlling tty. A `TRM-` ruling records the outcome. Proves a session leader with fds 0-2 only.
- **2.2 macOS and Linux runtime.** Read and write sources, `TIOCSWINSZ`, `killpg`, `tcgetpgrp`, reaping (process source; pidfd), EIO as end of file. Proves the POSIX pty test list of spec section 8.
- **2.3 Windows ConPTY.** Overlapped named pipes, `STARTUPINFOEX`, job object, threadpool IO, `ResizePseudoConsole`, signal mapping, close-drain. Proves exit, resize, job kill and close during output on the Windows runner and the ARM64 VM.
- **2.4 End to end.** A real shell through `TerminalSnapshotSource` on all three OSes.

## Phase 3 - surface-scoped redraw (gap 5; parallel)

- **3.1 Surface-only frame.** The window keeps the last frame's surface requests; `SurfaceRedrawTrigger` marks a surface pending; `drawFrameIfNeeded` gains a branch that re-encodes the last scene and runs only pending surfaces, forced past the target table's keep rule; a full frame whenever scale, atlas `layoutGeneration` or size changed. New `FrameWork.surfaceOnlyFrames`, `TestWindow` support. Proves 0 builds and 0 element requests on a surface-only frame.
- **3.2 Timed requests.** `requestRedraw(after:)` on a per-window deadline set anchored on the frame clock (`TW-A`). Proves blink cost on the simulated clock and a no-op for a hidden surface.
- **3.3 Surface replay.** A retained record re-appends the surface quad and request, so the `"surface"` taint goes. Proves an editor key frame with a terminal visible pays no terminal paint.

## Phase 4 - key capture (gap 3; parallel)

- **4.1 Window stage.** The modifier, the `KeyboardAttachment` field, the stage ahead of the Keymap, the Option raw-key hint (AppKit and SDL Alt). Proves the order matrix against each existing stage, the fall-through of `.ignored`, marked text, `except`, and Ctrl+Tab routing.
- **4.2 SDL key coverage.** Insert, F13-F20, keypad, Ctrl+\` and Ctrl+Space on X11, Wayland and Win32.

## Phase 5 - `TerminalView` (needs 1, 3, 4; gaps 2 and 5 freeze at its start)

- **5.1 Grid sink.** `SurfaceTextSink` extended into a package grid sink (glyph sprites plus solid rects), first as glyph instances over a reserved solid atlas slot, else `ReplaySurfaceQuads`; SDL fixture bump and parity frames.
- **5.2 Cell metrics and glyphs.** Metrics, the grapheme cache keyed on the atlas generation, synthetic box, block, braille and Powerline glyphs, wide cells.
- **5.3 The view.** Layout drives `onResize`; damaged-row redraw over the opaque background; cursor styles and blink with the idle stop; selection, underline, strike, dim, inverse, hidden, `boldIsBright`.
- **5.4 Input.** Capture plus `encodeKey`, IME text target at the cursor cell, paste, focus.
- **5.5 Pointer.** Wheel, mouse reporting, selection gestures, command-hover link queries.
- **5.6 Accessibility and demo.** Visible-rows text area; `METALUI_TERMINAL_DEMO=1` running `$SHELL`; human-check group `TRM1..n` (vim, less, htop, IME, VoiceOver).

## Phase 6 - performance and closeout

Gated bench (`METALUI_RUN_TERMINAL_BENCH=1`), memory probe, fuzz soak, Windows release build of the new products, `api-overview.md`, record entries, rule shards, CLAUDE.md counts.
