# MetalUI Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A GitHub Pages landing page that gets Swift developers to try MetalUI today, plus a DocC API reference under `/api/`, published from master by one workflow.

**Architecture:** Hand-written static `site/` (HTML + CSS, a few lines of vanilla JS) with real screenshots committed beside it. `scripts/build-docs.sh` turns symbol graphs from a normal `swift build` into a static DocC archive (no package dependency added). `.github/workflows/pages.yml` on the `xcode-27` runner assembles `site/` + the archive and deploys with `actions/deploy-pages`.

**Tech Stack:** HTML/CSS, zsh scripts, Swift-DocC (`xcrun docc`), GitHub Actions (`actions/upload-pages-artifact`, `actions/deploy-pages`).

**Spec:** `docs/superpowers/specs/2026-11-15-website-design.md` (read it first; its "Answers to the builder check" section is binding).

## Global Constraints

- Worktree `~/Developer/worktrees/MetalUI/website`, branch `feat/website`. Never edit `~/Developer/MetalUI`. Never `git add -A`; never commit `.swift-version` or the untracked `MetalUI` entry; never force-push.
- Site URL `https://mburger89.github.io/MetalUI/`; API reference at `https://mburger89.github.io/MetalUI/api/`; DocC `--hosting-base-path MetalUI/api`. No custom domain. `site/.nojekyll`, `site/404.html`.
- No package dependency added; `Package.swift` and `.github/workflows/swift.yml` unchanged; root test count unchanged.
- No JS framework, no third-party scripts, fonts or trackers; system font stacks. Total `site/` weight (HTML+CSS+JS+images) ≤ 1.5 MB.
- Only real screenshots, captured on this Mac or in Docker. Showcase captures show demo content only: no private files, sessions, tokens, emails or usernames. Windows: no screenshot until the VM is back; never faked.
- Every number on the page cites what was measured and links its `docs/record/` file.
- "Experimental — the API still changes." appears once, next to the install step.
- No iOS/iPadOS/tvOS/watchOS/visionOS claims (PB-A).
- Docker: delete every container, image and volume you create as soon as you've read its result. No computer use (`screencapture` from Bash is fine). Stop background processes before finishing. PAUSE = start no local runs until RESUME.

## Review Focus

1. Phone width (375 px): no horizontal page scroll, code blocks scroll inside themselves — `check-site.sh` cannot see this; Task 3 verifies with a headless render.
2. Linux user without SDL3 installed runs the quick start — the Linux tab must state the SDL3 install step before `swift run`; Task 1 verifies it from a clean container.
3. Visitor with JS disabled — commands still readable and selectable; copy buttons are progressive enhancement (Task 3).
4. Deep link into `/MetalUI/api/documentation/metalui/...` loads with styles (base path right) — Task 5 checks a nested page's asset URLs.
5. Dark mode — every text/background pair readable in both schemes; screenshots don't vanish on dark backgrounds (Task 3).
