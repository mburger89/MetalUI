# 294. Capsule shapes for controls: `buttonBorderShape`, the segmented shape, the tab strip's selected tab (`BY-L`, `BY-M`, `SD-E`, `TBS-M`)

Branch `feat/button-border-shape` from master `eb8d4b8c`. Alloy gap G46: pills for buttons, menus, pickers, segmented controls and the selected tab of a `TabStrip`. Rulings in `docs/superpowers/2026-10-31-styles-decisions.md` (`BY-L`, `BY-M`), `2026-11-01-segmented-dark-decisions.md` (`SD-E`) and `2026-11-07-tab-strip-decisions.md` (`TBS-M`). Class A for `buttonBorderShape`/`ButtonBorderShape` (probe `swiftui-button-border-shape.swift` BO0, a type-check against the macOS 27 SDK), class M for `segmentedPickerShape(_:)` and `TabStrip.selectedTabShape(_:)`. No divergence label (two absences in "Not offered").

- **API.** `ElementGroup.buttonBorderShape(_:)` and `ButtonBorderShape` with `.automatic`, `.capsule`, `.roundedRectangle`, `.roundedRectangle(radius:)` and `.circle`: SwiftUI's declarations (iOS 15 / macOS 12; `capsule`, `roundedRectangle(radius:)`, `circle` macOS 14, read from `SwiftUI.swiftinterface`). It is a plain `Hashable, Sendable` value, not a `Shape` and with no `Shape.buttonBorder` (a MetalUI `Shape` is main-actor isolated and cannot be an environment key's default): a row in "Not offered". The environment key is internal, as SwiftUI's `_buttonBorderShape`.
- **Who honours it.** `Button` with the bordered chrome (`.bordered`, `.borderedProminent`, automatic) and `.glass`/`.glassProminent`; `Menu` and `Picker(.menu)`, which are internal bordered `Button`s (there is no `.menuStyle`). `.plain`, `.borderless`, `.link`, custom styles, the radio group and the segmented picker ignore it. The radius is written at paint from the bounds (`half the shorter side` for `.capsule`/`.circle`; the radius clamped for `.roundedRectangle(radius:)`), so the fill, border, pressed wash and 2-point focus ring all follow it, whatever the label's height; `.automatic` writes nothing (byte-identical scene, pinned for seven controls). A caller's `.cornerRadius(_:)` outranks it. Glass is the same `GlassBox` under `.automatic`/`.capsule`, a `RoundedRectangle` under `.roundedRectangle`.
- **Segmented.** Not read from `buttonBorderShape`; a MetalUI-only `segmentedPickerShape(_:)` (`SD-E`): `.automatic` 6/5, `.capsule` 12/12 (half the 24-point row), `.roundedRectangle(radius:)` r and r-1; the `SegmentedThumbEdge` hairline stays. SwiftUI's behaviour for segmented + `buttonBorderShape` could not be measured (every offscreen capture is blank on macOS 27), so a container's `.buttonBorderShape(.capsule)` is not allowed to reshape it silently.
- **TabStrip.** `selectedTabShape(_:)` with `TabStripSelectionShape` (`.rectangle` default, `.capsule`, `.roundedRectangle(radius:)`): the selected fill and hover wash as the shape inset 4 above and below and 3 at the sides, no tab hairlines; the default tree is untouched (an `if` around the row).
- **Not done.** Hit areas stay rectangles (MetalUI's hitboxes are rectangles for every rounded control); a capsule button's padding is unchanged (SwiftUI's capsule metrics are unmeasured); `.circle` on a non-square button is a capsule (SwiftUI's is unmeasured).
- **Tests** (`ButtonBorderShapeTests`, 11, plain imports, `harnessTextSystem`, so Linux and Windows run them): `aCapsuleBorderedButtonHasHalfHeightCornerRadii`, `aRoundedRectangleShapeUsesItsRadiusAndClampsToHalfTheHeight`, `anAutomaticBorderShapeDrawsTheSameSceneAsNoModifier`, `theShapeReachesButtonsThroughTheEnvironmentAndTheNearestWriterWins`, `stylesWithoutABorderIgnoreTheShape`, `aProminentButtonFollowsTheShapeAndACallersRadiusOutranksIt`, `aGlassButtonFollowsTheShape`, `aMenuAndAMenuPickerFollowTheShape`, `theFocusRingFollowsTheShape`, `aSegmentedPickerTakesItsOwnShapeAndIgnoresTheButtonBorderShape`, `aTabStripDrawsItsSelectedTabInTheShape`.
- **Mutations** (each restored): M1 the paint-time radius write removed: the capsule, rounded, environment, ring, menu and prominent arms redden; M2 glass always a `Capsule`: the glass test; M3 segmented radii fixed at 6/5: the segmented test; M4 the tab strip ignoring its shape: the tab-strip test; M5 `.automatic` treated as `.capsule`: the automatic-scene test.
