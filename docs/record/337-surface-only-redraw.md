# 337 - surface-only redraw (`TRM-P`..`TRM-T`)

Branch `feat/surface-only-redraw` from master `ff73af7c`. Terminal plan Phase 3.1 and 3.2 (Alloy gap 5, draft until Phase 5). Class M, no divergence (SwiftUI's `Canvas` redraws with its body; there is no handle to compare). Surface replay (3.3, removing the `"surface"` retention taint) is **not** here.

**What landed.** `SurfaceRedrawTrigger` (`requestRedraw()`, `requestRedraw(after:)`, any thread, coalesced, earliest deadline wins), `GPUSurface(redraw:value:trigger:draw:)` and `GPUSurface(redraw:trigger:draw:)`. `Window.drawFrameIfNeeded` gained one branch, taken when the window is not dirty, not animating, has no gesture or tooltip timer and a surface is pending: it re-encodes `lastScene` with the same atlas and hands the renderer only the pending surfaces' requests, forced past the table's keep rule (`SurfaceDrawRequest.isForced`, `package`). A full frame forces the same requests, so a trigger is never lost. The scene is reused only while the scale, content size, resize count and atlas `layoutGeneration` are what the last full frame had (a scale or size change also dirties the window; the atlas case dirties nothing, which is why the guard exists). `SurfaceRedrawState` (new, window-owned beside `SurfaceRegistry`) holds the last requests, the pending set, the bound triggers and the deadlines. Timed requests anchor on the frame clock (`TW-A`): the timeline store's date at the last tick under the simulated clock, the wall clock in an app, with one `Task` wake in an app and the display-link tick firing due deadlines under the harness.

**Renderers.** Unchanged beyond `SurfaceTargetTable.update` reading `isForced`; both call the table. `Backends/SDL` builds (see below).

**Harness.** `FrameWork.surfaceOnlyFrames`; `TestWindow.runsSurfaceDraws` and `surfaceDrawCount` (the headless renderer now runs a `SurfaceTargetTable` every frame and calls the draws only when the flag is on, so the `HT-Q` recorded-never-run default stands); `runUntilIdle()` counts a pending surface as work.

**Where it differs from the draft** (`TRM-S`): `@unchecked Sendable` (a lock around mutable state), one extra initialiser without `value:`.

**Tests** (`Tests/MetalUITestingTests/SurfaceOnlyRedrawTests.swift`, 15, portable, `harnessTextSystem`), each with its mutation in its doc comment. Red against: trigger routed through `setNeedsRedraw` (tests 1, 3, 10, 12 and others: builds 1, no surface-only frame); the surface-only frame forcing every surface (3); the request not consumed (2, 4, 5, 12, a 64-round `runUntilIdle` failure); a later deadline replacing an earlier one in the window (5) and, off the main thread, in the trigger (5); the trigger left bound when its surface is not painted (6); deadlines of unpainted surfaces kept (7); a full frame not forcing (8, 11); the atlas generation dropped from the reuse guard (10); the surface-only branch taken while animating (11); the off-main hop removed (12, 5); a deadline firing at the first tick (4).

**Steady-frame cost** (`TRM-T`; tests 13 to 15; the shared-view rule). Literals measured on master `ff73af7c` in a worktree and on this branch, identical: a `VStack { Text; GPUSurface }` with no trigger 3 element requests, 0 retained occurrences; a plain `VStack { Text; Text }.frame` 3; an `.equatable()` card holding an untriggered surface 2 requests, 0 hits, 0 misses, 1 ineligible, reasons `["surface": 1]`. A trigger's frame is 0 builds and 0 element requests (test 1).

**Limits.** A trigger serves one surface in one window. A surface-only frame skips accessibility, hover and lifecycle (nothing they read can have moved); a surface a full frame must still paint is painted in every full frame (3.3). A window that is animating or on a timer folds the trigger's draw into its next full frame. Off the main thread a delay is measured from the moment the main actor drains it, not the call.
