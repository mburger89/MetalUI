# 287 - `contentMargins` for scroll views (Alloy G43, `CMG-A`...`CMG-F`)

Branch `feat/content-margins` from master `e852cb12`. Class `A`, no divergence added or retired. PR 1 of two: `ScrollView`, `ProposalScrollView` (and a `List` inside one); `CodeView` is PR 2.

**What.** Alloy floats glass bars over scrolled content (tabs and a header over a code view, a composer over a chat). SwiftUI's answer is `contentMargins` (macOS 14): `contentMargins(_:_:for:)` with an `EdgeInsets` or a length on an `Edge.Set`, `contentMargins(_:for:)`, and `ContentMarginPlacement` (`.automatic`, `.scrollContent`, `.scrollIndicators`). `safeAreaInset` is not used: safe areas are `PB-A`.

**How.** A modifier on any `ElementGroup` writes an internal `EnvironmentValues.contentMargins` (per edge, per placement, the nearest write wins). A scroller reads it in layout and wraps its content node in a native padding node when a scroll-content margin is set, so the content's extent includes the margins and every consumer of that extent agrees. `ScrollerFrame.inset` carries the margins to `scrollTo` and `scrollPosition(id:)`, which measure the viewport minus them. `ScrollChrome` carries the indicator insets and shortens the thumb's track. A change of a margin is a relayout (equal components are not rebuilt) and a bottom-pinned scroller stays pinned in the same frame.

**Tests** (`Tests/MetalUITestingTests/ContentMarginsTests.swift`, each shown to fail by mutation, `docs/superpowers/2026-11-13-content-margins-decisions.md`): `scrollContentMarginsPositionTheContentAtBothEnds` (padding node dropped), `contentStillDrawsAndScrollsUnderTheMarginRegion` (a clip at the margin), `aScrollIndicatorsMarginMovesOnlyTheIndicator` (indicator inset ignored), `marginsAddToTheContentsOwnPadding`, `aNearerMarginOverridesTheOneAbovePerEdge` (a write replacing every edge), `scrollToPlacesATargetInsideTheMargins` (margins left out of `scrollOffset(bringing:)`), `aBottomPinnedScrollerFollowsAChangingBottomMargin` and `aScrollerAwayFromTheBottomKeepsItsRowWhenTheBottomMarginChanges` (the anchor's placement removed), `aMarginChangeRelaysOutWithoutRebuildingTheContent` (the component made unequal), `aListInsideAScrollerGetsTheMargins`; the environment guards in `RetainedSubtreeInternalTests` and `RetainedAmbientMissTests` gained the `contentMargins` field (35 fields).
