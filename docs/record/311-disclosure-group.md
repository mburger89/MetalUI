# 311 - `DisclosureGroup` in eager contexts (`OG-`, lane 1)

Branch `feat/disclosure-group` from master `4a314eed`. Lane 1 of the hierarchical lists (design `docs/superpowers/specs/2026-11-15-outline-disclosure-design.md` section 8; decisions `docs/superpowers/2026-11-15-outline-disclosure-decisions.md`). Class A, **no new divergence label** (1085-1094 stay reserved, none used). Finalises `OG-A` (its `DisclosureGroup` part), `OG-D` (its storage), `OG-H` (its eager part) and `OG-J` (its chevron look); `OG-F`'s standalone-group accessibility is recorded as MetalUI's choice.

**API.** `DisclosureGroup<Label: ElementGroup, Content: ElementGroup>` (`Sources/MetalUI/DisclosureGroup.swift`): `init(content:label:)`, `init(isExpanded:content:label:)`, and the `Label == Text` forms over `LocalizedStringKey` and over `StringProtocol` (`@_disfavoredOverload`), with and without `isExpanded:`. `content` is `@escaping` and called only while expanded. The generics are `ElementGroup` (the design said `Element`; `Toggle` and `Button` take `ElementGroup` labels). `LocalizedStringResource` forms and `DisclosureGroupStyle` are class R.

**Construction.** An `ElementGroup` that delegates its three phases to an internal `Component` (`DisclosureGroupBody`, public only because `GroupLayout` names it), so the uncontrolled state is that component's `@State` at the group's own id (collapsed initially, `D4`; no new reserved slot name, `theSevenRetentionSlotsAreMutuallyDistinct` unmoved). Its content is a native `VStack(alignment: .center, spacing: 0)`: the label row, then `if isExpanded { makeContent() }`. The label row is a plain `Button` over an `HStack` (chevron cell, label, `Spacer`) `.frame(height: 24)`, so focus, Space, press, the disabled gate and the focus ring are the `Button`'s.

**Look (D1).** 24 pt label row; chevron `chevron.right` collapsed and `chevron.down` expanded (a glyph swap, `P-L3`) at 9 pt semibold in `.tertiary`, centred in a 9 pt cell inside a 12 pt slot, so the label starts at +12 (probe ink 12.5); content centred in the group's width with no spacing and no indentation (a nested group starts at its parent's x). Tests assert the probe's values: collapsed 260 x 24, expanded 260 x 56, content at +24, children at (260 - 75) / 2 and (260 - 74) / 2, nested 260 x 64 with the leaf at 116.5.

**Animation (D3).** The content sits under a builder `if`, so it is a `XF-H` default unit: a bare binding write snaps, and under `withAnimation` the content fades in (0, 0.33 at 0.4 of a 1.2 s ramp, 1) and out as a ghost. **A click writes bare**: SwiftUI's click animation (`D3c`) is unmeasured, so a click snaps (decision `OG-H`).

**Accessibility (MetalUI's choice; `P-A3` unmeasured).** A new case of the role-hint enum behind `AXNode.progressHint` (`.disclosureTriangle`, stripped like the other hints; a seventh `Bool` grew `AXNode` past `theNewDeclarationsCostHandlersAtMostOnePointer`) and a new `AccessibilityRole.disclosureTriangle`: AppKit `AXDisclosureTriangle`, value `"1"`/`"0"` (the value the outline probe read on the real triangle), press toggling; SDL/AccessKit maps it to `BUTTON` (the `accesskit.h` header is not available here, so no new C name; the AccessKit expanded state is left to lane 5). The chevron is `accessibilityHidden`: left visible it folded the symbol's own label ("Forward") into the row's.

**Not done / not measured.** The chevron's ink size and colour against the real control (the tests assert layout boxes: 8 x 10 right, 10 x 7 down, against the probe's ink 5 x 8 and 8 x 5), the dark chevron (the probe's #FFFFFF was an unchecked sample), SwiftUI's own AX tree for a standalone group, whether SwiftUI's header takes Space (MetalUI's control convention, divergence 80's family), and whether the rows below slide with the insertion under `withAnimation` in MetalUI. The SDL change was not compiled here (the SDL package needs its fetched headers).

**Tests** (`Tests/MetalUITests/DisclosureGroupTests.swift`, 13): geometry (24 / 56, content x, nested, title forms, glyph swap), content call counts, click toggle and persistence, controlled write-only-by-input, Space, disabled (with an enabled control arm), accessibility value and press, bare snap versus animated fade. Mutations that reddened them: row height 25 (6 tests), content built unconditionally (`aCollapsedGroupNeverCallsItsContent`), a no-op toggle (4), no role hint (3), no value (the accessibility test), a write from the build (3), the chevron always right (`theChevronIsAGlyphSwapNotARotation`), a content slot that is not a unit (the animated arm reads 1).

**Bookkeeping.** Inventory family `disclosure-group` (class A, probe arm `D1`); `docs/api-overview.md`; the `docs/rules/input-focus.md` rule; `OG-` row in `docs/rules/decision-prefixes.md`; the reveal note (Alloy accepts a same-transaction expand + `scrollTo` landing in the same frame, unlike SwiftUI; the divergence is added by lane 4 or 5) under `OG-D`.
