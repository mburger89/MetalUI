**The spike (2.1).** `posix_spawn` with `POSIX_SPAWN_SETSID` gives the child a controlling terminal on macOS 27 (Darwin 27.2) and on Linux (glibc 2.39, Docker `swift:6.4-noble`): the child opens the slave as its first file action and, being a session leader with no controlling tty, acquires it. Evidence, both mechanisms: `getsid(child) == child`, `echo > /dev/tty` succeeds, and `tcgetpgrp` on the master answers the leader's group. So the macOS `fork` fallback is not needed; the C `fork` path is kept (and tested on both OSes through `Mechanism.fork`) because a glibc older than 2.34 or musl lacks `addclosefrom_np`, which `posix_spawn` needs to keep fds above 2 out. Two things the spike found: Darwin drops a `TIOCSWINSZ` made on a pty nobody has opened (`stty size` printed `0 0`), so the parent holds the slave open across the spawn and sets the size on it; and the shell's own fd 10 shows up in an fd probe under a plain `sh -c`, so the test excludes it and leaks fds 12 and above instead.

**Runtime (2.2).** Read and write through dispatch sources on a non-blocking master; end of file is latched because a read source is level-triggered; reaping through a process source (macOS) or pidfd (Linux) with a shared poll fallback; one lock covers reap, `signalGroup` and the descriptor so a pid or fd is never used after it is gone. Detail is in `TRM-K`..`TRM-O`.

**Tests** (`Tests/MetalUITerminalTests/PseudoTerminalTests.swift`, 23 tests, nearly all run under both mechanisms, bounded waits only, `--no-parallel`): `tty` names a pty; session leader with a controlling tty; only fds 0-2 (a deliberately inheritable parent fd does not leak); exact environment and cwd; missing executable or cwd is `spawnFailed(ENOENT)`; `stty size` follows a resize; `exit 7` is `.exited(7)`, `kill -9 $$` is `.signaled(9)`; `signalGroup` kills a grandchild that ignores SIGHUP (so only the group signal can); a no-op after the reap; `.interrupt`; the foreground group leaves the shell under a job-control `sleep`; 50 MB of `yes | head -c` arrives complete (count and byte sum; one mechanism, a pty moves about 1.7 MB/s on macOS so it takes about 50 s in debug); 400 000 numbered lines arrive in order; a 1 MB write to a child that does not read returns; a 1 MB write in three calls reaches a `head -c | cksum` child with the right POSIX CRC; no callback after `close()` during a flood; `close()` idempotent and harmless; Linux only, the shared-reaper fallback.

**Mutation results** (each mutant built, the named test run, source restored by `cp`, `git status` checked). Two guards were first green and were repaired, which is the finding: (1) `killpg(pid, ...)` replaced by `kill(pid, ...)` left `signalGroupKillsAGrandchildToo` green, because a dying session leader revokes its tty and hangs up its foreground group, so a plain `sleep` died anyway and the master reached end of file either way; the grandchild now ignores SIGHUP, the test reads its pid and polls `kill(pid, 0)` (bounded), a control test shows the leader dying alone leaves it alive, and the mutant is RED. (2) `write` made synchronous (`writeQueue.sync`) stayed green against `sleep 300`, because canonical-mode input is discarded rather than blocking and a synchronous non-blocking drain does not block; the child now runs `stty raw -echo` first and the mutant (sync plus `O_NONBLOCK` removed) is RED after 20 s. The rest were red at once: `foregroundProcessGroup()` returning the pid; `write` truncating to 64 KB; not cancelling the read source and dropping the closed check; `resize` a no-op; `POSIX_SPAWN_SETSID` dropped; `CLOEXEC_DEFAULT` dropped (fd leak); exit status decoded without the shift; EAGAIN treated as end of file (red on the 50 MB flood). Also found while writing the tests: `"\r\n"` is one `Character`, so `String.contains("\n")` never matches a tty line.

**Verification.** `swift build --build-system native --build-tests && swift test --build-system native --no-parallel`: 6294 tests in 34 suites passed (the Swift Testing summary line; no failure line anywhere); Linux (`swift:6.4-noble`, fresh scratch path, container and nothing else created, removed): 23 tests green including the shared reaper; the 50 MB flood takes 0.4 s there. `zsh docs/probes/closeout-inventory-check.sh` and `closeout-undocumented.sh` print nothing (`MetalUITerminal` joined `closeout-public-api.sh`'s target list; family `terminal-pty`).
