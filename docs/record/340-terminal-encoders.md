# 340 - Terminal encoders (`TRM-AI`..`TRM-AL`)

Branch `feat/terminal-encoders` from master `0dfd9f13`; Phase 1.7 of `docs/superpowers/plans/2026-11-16-terminal.md`. Class M, no divergence label. Ids `TRM-AI`..`TRM-AL` only (a parallel branch holds `TRM-AE`..`TRM-AH`, so this number and the README row may need renumbering when the two merge).

**What landed.** `TerminalEncoder` (`encodeKey`, `encodeMouse`, `encodePaste`, `encodeFocus`), `TerminalKey`, `TerminalModifiers` and `TerminalMouseEvent` in `Sources/MetalUITerminal/TerminalEncoder.swift` and `TerminalInput.swift`: pure functions of `TerminalModes`, no UI import. The tables are in the rulings; they were written from xterm's ctlseqs documentation, not from any implementation.

**Judgement calls.** The frozen `TerminalKey` could not spell a keypad key and the frozen mouse `Kind` had no horizontal wheel; Alloy approved two additive amendments on 2026-11-16 (`TerminalKey.isKeypad` with DECKPAM `SS3` encoding, and `wheelLeft`/`wheelRight` as buttons 66 and 67), now in the spec and `TRM-AI` item 2. Option on special keys is the Alt parameter whether or not `optionAsMeta` is on (`TRM-AJ`). The `MetalUITerminalUI` `KeyPress` overload is not part of this phase.

**Tests.** `EncoderTests.swift`, 26 tests (the keypad adds literal tables for all 18 keypad keys in application mode with the seven modified rows each, numeric mode, and non-keypad keys; wheelLeft and wheelRight are covered in the mode matrix, SGR, legacy and UTF-8 with modifiers): every cursor key, Home, End, Insert, Delete, page key and F1-F4 in all eight Shift/Option/Control combinations and both cursor modes (expected parameters written out as literals, not computed), F5-F20 by the xterm numbers, Control letters and punctuation, editing keys, option-as-meta, Command to `[]`, the mouse reporting matrix by mode, SGR codes with modifiers, legacy bytes, the 223 limit, UTF-8 coordinates, paste stripping of every C0 and an embedded `ESC[201~`, focus. Mutations shown red: modifier parameter off by one, SS3 and CSI swapped, Control bit wrong, an F-key number moved, legacy limit moved (the report byte overflows and traps), paste keeping ESC, SGR release letter, Command not empty, meta ignoring the flag, Control+Backspace, wheel code, legacy column off by one, focus swapped, x10 reporting releases, keypad final swapped, `applicationKeypad` ignored, keypad modifier parameter dropped, wheelLeft code 66 to 67, wheelRight reported in x10.
