# 253. A menu `Button`'s `.accessibilityIdentifier` and `.help` reach the menu item (Alloy gap G24, `MN-AL`)

Branch `feat/menu-item-id-help`. Alloy's sidebar `Menu` has Fork and Rename items; tests want `fork-<uuid>` ids and a disabled Fork wants the help "Nothing to fork yet". Both values were already on the `Button`'s handlers (`axNode.declarations.identifier`, `contextual.help`) and were dropped when menu content lowered to `MenuNode`.

- **Model.** `MenuNode` and `PlatformMenuItem` gain `accessibilityIdentifier` and `help` (defaulted `nil`); `Button` and `Toggle` fill them in `_menuNodes`; `MenuSession.number` and `CommandBar.number` pass them to the platform item. `PlatformMenu.item(accessibilityIdentifier:)` is a depth-first lookup. Public API: two properties, one initialiser spelling, one method on `PlatformMenuItem`/`PlatformMenu` (map rows `menu-item-id-help`).
- **AppKit.** `AppKitMenuBuilder.fill` sets `toolTip`, `identifier` and `setAccessibilityIdentifier` on an action item.
- **Headless.** The recorded `PlatformMenu` carries both; `TestWindow.presentedMenu?.item(accessibilityIdentifier:)` finds an item (`HT-X`).
- **SDL / drawn menu.** `appendMenuPanel` sets `identifier` and `hint` on each row node (the AccessKit bridge already sends `author_id` and `description`, `IX-AD`); `trackTooltip`'s open-menu branch, which hid the tooltip, now starts the usual tooltip over a row with help (`trackMenuRowTooltip`), a disabled row too. No new mechanism. Not done: a tooltip for a submenu row (a `Menu` item has no `.help` today) and for the menu bar's drawn strip titles.
- **Probe** `docs/probes/swiftui-menu-item-id-help.swift` (compiled with `xcrun swiftc`, run headless, macOS 27.2): `.help` reaches `NSMenuItem.toolTip`, a disabled item's too; `.accessibilityIdentifier` reaches neither `identifier` (SwiftUI's own `menuAction:`) nor `accessibilityIdentifier()`. MetalUI carries the identifier anyway (class M, no divergence).
- **Tests.** `MenuItemIdentifierHelpTests` (4), `HarnessMenuTests.aPresentedMenuItemIsFoundByIdentifierAndKeepsItsHelp`, `AppKitMenuTests.anAppKitMenuItemCarriesItsIdentifierAndHelp`.
- **Mutations** (each applied alone, filtered run of those six, then restored): **M1** `Button._menuNodes` passes `nil, nil`: `aMenuButtonsIdentifierAndHelpReachThePlatformMenuItem`, `aDisabledMenuItemKeepsItsHelp`, `aDrawnMenuRowPublishesItsIdentifierAndHelp`, `aDrawnMenuRowShowsItsHelpAsATooltip`, `aPresentedMenuItemIsFoundByIdentifierAndKeepsItsHelp` red. **M2** `Toggle._menuNodes` passes `nil, nil`: `aMenuButtonsIdentifierAndHelpReachThePlatformMenuItem`, `aDrawnMenuRowPublishesItsIdentifierAndHelp`. **M3** the two lines in `appendMenuPanel` dropped: `aDrawnMenuRowPublishesItsIdentifierAndHelp`. **M4** `trackTooltip`'s menu branch back to `tooltipTracker.hide()`: `aDrawnMenuRowShowsItsHelpAsATooltip`. **M5** `toolTip` line dropped: `anAppKitMenuItemCarriesItsIdentifierAndHelp`. **M6** `setAccessibilityIdentifier` dropped: `anAppKitMenuItemCarriesItsIdentifierAndHelp`. **M7** `help: isEnabled ? node.help : nil` in `MenuSession.number`: `aDisabledMenuItemKeepsItsHelp`, `aDrawnMenuRowPublishesItsIdentifierAndHelp`, `aDrawnMenuRowShowsItsHelpAsATooltip`, `aMenuButtonsIdentifierAndHelpReachThePlatformMenuItem`, `aPresentedMenuItemIsFoundByIdentifierAndKeepsItsHelp`. **M8** `Toggle` help `nil`: `aMenuButtonsIdentifierAndHelpReachThePlatformMenuItem`.
