**What landed.** `TerminalEmulator.resize(cols:rows:)` (frozen signature, clamps to 2 x 1, a no-op at the same size). The primary screen and its scrollback are rewrapped by the soft-wrap flag; the alternate screen clips. `TerminalSnapshotSource`'s default `resizeHandler` calls it (a newer pending resize still replaces an older one). New public surface: `TerminalEmulator.reflowGeneration` and `TerminalSnapshot.reflowGeneration`, the one integer a selection compares (Phase 1.6).

**The rules chosen** (full text in `TRM-AM`..`TRM-AO`).
- *Numbering.* The oldest retained row keeps its absolute number; `firstRow` advances only by rows the capacity evicts. A height-only resize keeps every number and text; a width change renumbers and increments `reflowGeneration`; the snapshot is a full frame either way. A selection (1.6) is valid for one generation and is cleared by a later one.
- *Rewrap.* Logical lines join across the scrollback and screen boundary; trailing default blanks are not carried; coloured blanks are; a wide character moves whole to the next row, leaving one empty column that is not text; the cursor stays on its character (a cursor past the text keeps its column through blanks that exist only for it; a pending wrap survives only when the line ends exactly at the edge); the saved-cursor slot of the primary screen follows the same way.
- *Rows.* Growing pulls rows back from scrollback and moves the cursor down; shrinking drops blank rows below the content first, then pushes the top rows to scrollback, never moving the cursor off the screen (xterm and Terminal.app behave alike). The scroll region resets, tab stops keep their columns and default beyond them, DECSC on the alternate screen clamps. While the alternate screen shows, the primary reflows behind it anchored by its 1049 slot.
- *One behaviour change outside resize.* `TerminalRow.compact()` no longer trims trailing blanks of a row that wraps to the next: they are text of the longer line (without this a scrolled-off wrapped row lost a real space and the round trip failed; the fuzz found it).

**Skipped / seams.** No selection, no viewport scroll (1.6); no event for a resize (the owner calls `PseudoTerminal.resize`); xterm's "save the line leaving a pinned-footer region" stays out (`TRM-AA` 2).
