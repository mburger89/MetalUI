## 4. What the code forced (deviations from the plan)

1. **Barrier.** `RenderEffects.withoutRenderEffects` pushed its `Deferred` barrier only when an effect, shadow or blur scope was open; it now also pushes it for a composite scope (M13). A `Deferred` inside an opacity group is outside the group and, drawing under the cleared opacity base, is **no longer faded** by the group's opacity (it was per primitive before). Carried in `GO-` "Carried".
2. **Surfaces.** A group holding a `.surface` is not marked, like a backdrop (the plan named only backdrops): both renderers resolve a surface's target from the root scene's references, a group scene's are not in them. 222 says so.
3. **The atlas.** The plan put `mui_renderer_render_group` between `begin` and `finish`; the atlas is uploaded inside `finish`, and a group may hold glyphs, so the groups render **inside** `finish` (and `replay_render`) between the atlas copy pass and the frame's passes, from descriptors (`ReplayGroup`), with the groups' records appended after the root's in one buffer per kind. `backdrop_begin_frame` moved to the callers and the single-pass path releases only unused slots.
4. **Two flattenings.** `MetalUISDL` cannot import `ReplayFixture` (the root manifest does not declare it), so the Scene-tree flattening exists as `SDLGroupSet` (live) and `FlatFrame` (fixture and replayer): same arithmetic, pinned by `aFlatFrameShiftsTransformsRunsAndGroupTextures`, `aGroupsTransformIsNotTheRootsTransform` and parity frame 16.
5. **Box.** Computed from the inner scene after insertion (`Scene.paintedBounds()`), not from the leaves' bounds: a CPU raster's extent (a shadow's blur reach) is only known once it has become an image.
6. **Pins moved outside the planned files, each with its cause:** `aNonAnimatableComponentAllocatesWhatItDid` 398 to **397** (`processScopes` hands its one leaf group to `insertLeaves` directly, where the old loop made a tuple-array copy: one allocation fewer, a count that moved on purpose); `sceneSideTablesArePlainIntArraysThatKeepCapacityAcrossClear` ten to **twelve** `[Int]` tables (`groupSequence`, `groupLayer`; the test now also inserts groups); `everyFrameChannelIsClassified` gained three `.frameLocal` rows (`groupsComposited`, `groupsBaked`, `groupsFlattenedOversize`); `anExhaustiveSwitchOverPrimitiveKindNeedsABackdropArm`'s "current" fixture gained a `.group` arm (the public break of `PrimitiveKind`); the exhaustive `PrimitiveKind` switches of `SceneFinalizeIdentityTests` and `DecorationPaintTests` gained an arm; `ReplayFixtureTests`: the version literal 6 to 7, the old-version builders strip the group count (`asVersion6`), and the "unknown run kind" probe uses 5 (4 is a group run now). `CompositingGroupTests`'s `aCompositingGroupDoesNotCompositeAnOpacity` was replaced by `aCompositingGroupCompositesAnOpacity`, as planned. No other pin moved.
7. **No pooled scratch `Scene`** and no cross-frame group texture cache (the plan said "pooled fresh `Scene`"; a `Scene()` per group measured nothing to pool).
8. **A unit inside an open opacity group has no default ghost** (the existing "composite scope collects and re-emits" rule now applies to opacity groups too).
