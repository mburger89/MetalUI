# 318 - The content form's flatten cache, the idle-frame guard and the 100k outline (`OG-`, lane 8)

Branch `feat/outline-performance` from master `aad96831`. Lane 8 of the hierarchical lists (design `docs/superpowers/specs/2026-11-15-outline-disclosure-design.md` sections 2, 6, 8 and 9a item 1; decisions `docs/superpowers/2026-11-15-outline-disclosure-decisions.md`, `OG-I` finalised and `OG-O` added). Class A for the behaviour (no public API; the `FrameWork` counters are test surface), **divergence 1087 added** (live count 224, next label 242).

**Why.** Alloy's content form, `List(selection:) { ForEach(model.roots) { NodeRow(node: $0) } }` over `@Observable` classes, evaluated every row body of every expanded folder on every frame (record 312). Alloy adopts only when an idle frame does zero outline evaluation and its steady-frame guard (`ViewRerunTests`) does not rise.

**How** (`Sources/MetalUI/OutlineContentCache.swift`). The reuse is the retained-subtree machinery, not a new mechanism. The list's walk (`lazyFlattenRoot`) runs behind `lazyFlattenRootCached` (only when `ListContentEngine` sets `LazyStackEngine.cachesFlatten`): a memo entry the list owns (`ContentMemoStore.flattenEntry(for:)`, swept with it) holds the cache and the walk runs in that entry's `buildSession` (the observation session of a retained subtree's build), inside a `BuildJournal` window (`openGraftWindow`). A cache is the walk's sources plus the window's journal slice. A **hit** needs `!entry.observedChange`, an equal `BuildKey`, every `@State` the walk read at its version and every nested memo entry valid (`GraftRecord`'s own tests, copied), and the list's **top level equal by value** (below); it applies the journal through `Frame.reapply` and returns the cached sources, so no row body, no `ForEach` closure below the top level and no flatten runs, and only the window is realised from the cached groups. A **miss** walks and records, unless the walk must not be reused (below).

**The top level** is what the list's own content is made of, outside any observation: the `ForEach` data's ids and what its closure makes of each element (called once per top-level element, no body run, counted `outlineContentChecks`), a component's fields, static members. `lazySameValue` compares by `==` when `Equatable`, by identity for a class, field by field through `Mirror` for a struct, tuple, optional or collection (a `State` or `Environment` wrapper skipped, a closure unequal to everything). So a data array that changed, or a value the closure captured (`ForEach(roots) { NodeRow(node: $0, prefix: prefix) }`), is never missed.

**What the cache refuses** (the walk runs every frame, exactly as lane 2): `OutlineWalk.unobserved` set by a component holding a class that is not `Observable` (checked once per component type, from its first instance, through `Mirror`; `@State` and `@Environment` fields skipped) or declaring `@Environment`, or a `ForEach` over such instances; a top level that cannot be compared; a walk with a journal taint (it wrote state), layout nodes or lowering records, a moved audited channel (animation, lifecycle, presentation, scroll keys, ...) or a lifecycle, presentation or window-preference note; a pending ⌥ cascade (which also drops the cache). Every lane 2 to 6 test models its tree with a plain class and so stays on the refused path, unchanged; the new tests use `@Observable`.

**Counters** (`FrameWork`, from `LazyWork`): `outlineContentEvaluations` (a `ForEach` closure, a component body or a group's content evaluated by the walk), `outlineContentRebuilds` (walks run), `outlineContentHits` (walks a cache stood in for), `outlineContentChecks` (top-level closures called to compare).

**Measured** (`OutlinePerformanceTests.swift`, window level, 300 x 400). Idle: three expanded folders of six leaves, five frames with nothing changed: evaluations 0, rebuilds 0, hits 1 a frame, index rebuilds 0, no `NodeRow` body (the steady-frame guard's number), checks 3; the settling frames evaluated 45 a frame without the cache. Scroll: one expanded folder of 500 and of 5 000 leaves, scrolled the same, the same per-frame literals `[evaluations 0, rebuilds 0, hits 1, checks 1, units realised, index rebuilds 0]`. Model changes: a visible rename, an offscreen rename (right when scrolled to, 0 evaluations scrolling), a child added or removed, a root added, `isExpanded` written by the model, the chevron, ← → and ⌥→: one walk each, shown the next frame. A bound `@State` read by the walk (an uncontrolled group's slot) invalidates; 400 rows' states survive 12 idle frames (the journal's marks are replayed). The divergence 1085 reveal lands the row over the cache. **Gated** (`METALUI_RUN_100K_OUTLINE_TEST=1 swift test --filter anOutlinesWorkIsTheSameFor100kPathsAsFor500`, one run, debug build, this machine): 500 paths and 100 000 paths both read idle `[0, 0, 1, 5, 15]` and scroll `[0, 0, 1, 5, 17]` a frame (the first walk evaluated 339 and 4 319; an idle frame took 2.5 ms and 7.5 ms, a scroll frame 3.4 ms and 9.4 ms, the build and four settling frames 44 ms and 66 ms).

**Mutations shown to redden them** (each its own run of the file): the cache off (`cachesOutlineContent` false: the idle, scroll, rename, expand and state tests, 7); the journal not applied on a hit (the scroll test's mark-dependent literals, the states test, the offscreen rename: 3); the observation session removed (`buildSession.run` replaced by the bare walk: 6, every model change); the `Observable` check dropped (the plain-class test); the top level compared by nothing (the captured-value test and the add test); `stateReads` ignored (the bound-state test); `observedChange` ignored (6).

**Costs and gaps.** A hit is not free: it applies the journal (`O(calls the walk made on the state table)`, about 15 000 for the 100 000-path tree whose 2 000 folders are open, ~5 ms an idle frame; 0.3 ms at 500 paths) and compares the top level (`O(top-level elements)`: a flat list of 100 000 roots would pay 100 000 closure calls and compares a frame). The counts, which are the contract, are flat. An observed change re-walks the whole tree once, not just the rows that changed (the session is the list's, not each row's; a per-row session would arm one observation per row). A component with an `@Environment` field, or a row holding a `Binding(get:set:)`, is never cached. **Divergence 1087** records what remains unseen: a plain class reached only through a closure a row captures or below an `@Observable` object's property shows when something else invalidates the cache. Not done: the lane 7 splice animation. The demo (`METALUI_OUTLINE_DEMO=1`, `OutlineDemo.swift`: 100 000 paths, rename, add and expand buttons) is built and not run; human check `OG10`.
