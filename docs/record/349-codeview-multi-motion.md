# 349 - Motion and editing over every selection (`CV-BH`, `CV-BI`)

PR 4 of the editor-essentials plan for Alloy (G3); builds on the primary selection and batched edits of record 333 and the multi-caret drawing of record 344. Renumbered from 345 because #348 and #349 merged first.

**What landed.**
- Every motion maps each selection's head (extend keeps the anchor; a plain horizontal motion over a range goes to its edge), then `setSelections(_:primary: primaryIndex)` normalises and tracks the primary. One selection runs the old path (`moveOne`).
- Vertical motion keeps a goal x per selection: `CodeViewState.goalXs`, allocated only with more than one selection, guarded by the selection state's `mutationSerial` (`goalXsSerial`) so any foreign write ends the run. Plain-ASCII lines are read by column (x = column x `plan.spaceAdvance`), so 10 000 carets shape nothing; every other line goes through `plan.layoutRow`.
- Delete (all six kinds), cut, newline, indent and outdent make a range or text per selection, union the overlaps and apply one edit through the new `package` `CodeSelectionState.replaceEach` (`CodeBuffer.performEdits`): one edit coalesces as before, several are the `CV-BF` batch under `recordBatchUndo`, which merges like a keystroke (Alloy's answer 9). Undo and redo restore every selection and the primary.
- Copy and cut join every selection's text with the buffer's line ending (a caret contributes its line without the break, once per row, with several selections); paste spreads one line per selection when the line counts match (one trailing break ignored), else the whole text at each.
- `CodeCommand.collapseSelections` (Escape, no modifiers): several selections collapse to the primary (claimed), one is declined; it runs after `onKeyPress` and an open popover (`CV-AR`).
- No public API. The G5 seam for hidden rows is `move` and `destination` (buffer rows); nothing is hidden yet. `collapseToPrimary()` (G2, `CV-BJ`) replaces `selections = [primary]` in the Escape case when it lands.

**Costs.** Keystroke frames for typed, backspace, right, down, newline, tab and paste with 1, 3 and 50 carets: 1 request, 0 hits, 1 miss, 0 ineligible, 1 frame each, equal to master c9b7c7c0 measured at the same fixture (the literal test was run on a detached master worktree). 10 000 carets (10 000 lines, release): one keystroke and its frame (edit + normalize + plan + the harness's draw), `-c release`, `METALUI_RUN_CODE_PERF=1`, a loaded machine: typed character 5.2 ms, backspace 13.3 ms, arrow right 5.8 ms, arrow down 9.5 ms (all within 16 ms; pinned by `tenThousandCaretsTakeOneKeystrokeUnderAFrame`).
