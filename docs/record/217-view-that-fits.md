## 2. What changed

The design is the plan's, with these changes. **Kernel** `NativeNode.firstFitting` (`LayoutTree.swift`): `package` registrar, `measureBody` and `placeNative` as planned, `fitChoices`, `firstFittingChoice(_:)`; `markSpacers` stops, `spacingEdges` the first child's, `nodeSignature` tag 14. **Memo**: `Placed` and `TranslatedPlacement` carry `choices` by pre-order position, written back by both restores and compared by the verify blocks. **The verify mode found a bug in the plan's design**: a translated restore (`RG-E`) shifts every rect of the record by the origin's move, the zero rects of the unvisited candidates included, so the subtree-verify trap named node 0 at x = 10. `restoreFitChoices` re-zeroes the unchosen candidates' subtrees, and the verify blocks compare against the rects as restored. The plan's stop condition 3 did not fire (the choices restore bit for bit); this is the record's own fix. `subtreeSignature(s)` walk only the chosen child and mix the choice (the plan said "mix a node's choice": walking only the chosen child also keeps a moved occurrence's key equal, since the unvisited nodes' zero rects would otherwise move with the origin).

**Element** `ViewThatFits` and `Axis`/`Axis.Set` (new files). The span is the node range `(previous candidate, this candidate]`, asserted contiguous in debug builds; the plan's stop condition 2 did not fire for any element kind in the census. **Elision**: `Element.prepaintGroup` returns `PrepaintState?` and `nil` for a node in `Frame.elidedNodes`; `paintGroup` takes the Optional. **Retraction**: `FitNote` carries the node-index interval the scope's content registered (the plan tagged by the first node; an interval lets a scope over several candidates be retracted only when none is chosen), `LifecycleStore.retract`, and the presentation records. **Focus**: `resolveFocus` clears a focused id equal to or below an `elidedIDs` entry. **Retained**: `BuildAudit.fitContainers`, a graft window opened under a view is tainted, an `.equatable()` occurrence whose top nodes are all elided bypasses replay. A `graftRecord` guard was written and removed as unreachable (an occurrence's identity path includes the view's id).

**Group-level hooks that needed their own guard** (the compiler does not find them; reading every `prepaintGroup` and the census did): `GeometryChangeScope`, `ModifierKeysScope` (its layout now keeps its nodes), `IdentifiedGroup`, `ForEach`'s scroll-target note, and **`AnyElement`'s group entry, a copy of `Element`'s default that the census found unguarded** (4 extra prepaints, a button in the accessibility tree).

**The `prepaintGroup` census (stop condition 1).** 59 non-test files mention `prepaintGroup`; **6 needed an edit** for the Optional return (`ElementGroup.swift`, `AnimationScope.swift`, `CoordinateSpaceScope.swift`, `GeometryChange.swift`, `ListRows.swift`, `Picker.swift`), no test file did (the 13 call sites compile unchanged), and the apps built without a change (section 6). No asserts-compiler SIL crash could be tested (section 6).

**Is `Element.prepaintGroup` public API a third party implements?** It is a public method of an extension of `Element`, the witness of the public requirement `ElementGroup.prepaintGroup`. A conformer to `Element` does not implement it (it implements `prepaint`), so none is broken; a third-party `ElementGroup` that writes its own entry keeps its own `GroupPrepaint`; generic wrappers over `Content.GroupPrepaint` are unchanged. What does break: a caller of `element.prepaintGroup(...)` on a concrete `Element` that stores the result as `PrepaintState`, a conformer that spells `typealias GroupPrepaint = X.PrepaintState`, and a group entry that copies `Element`'s (as `AnyElement`'s does) without the elision check. `docs/migration.md` says so.

## 5. Behaviour changes for callers

New `ViewThatFits` and `Axis`; a module with its own `Axis` that imports `MetalUI` must qualify it (MetalCreator's `CreatorGeometry.Axis` did not collide, section 6). `Element.prepaintGroup`/`paintGroup` take `Optional` (migration). A candidate that is not chosen is built every frame and costs its build; time-driven work in it keeps the display link awake; `Deferred` presentations in it are laid out and never prepainted; window metadata in it still applies (219). A switch runs the new candidate's `onAppear` before the old one's `onDisappear`.
