# 339 - Terminal screen semantics (`TRM-Z`, `TRM-AA`..`TRM-AD`)

Branch `feat/terminal-screen-semantics` from master `aef27c0a` (the emulator core and parser, record 335); Phase 1.3 of `docs/superpowers/plans/2026-11-16-terminal.md`. Class M, no divergence label. Ids `TRM-Z` and `TRM-AA`..`TRM-AD` only; `TRM-K`..`TRM-Y` belong to parallel branches, so the decisions doc's "next unused" line (set to `TRM-AE`) will conflict when they merge. Record number 339: 336 (pty) and 338 (key capture) are on other branches.

**What landed.** The emulator gives the screen its semantics. Implemented: cursor motion within margins and origin mode (CUU CUD CUF CUB CNL CPL CHA HPA HPR VPA VPR CUP HVP), CHT CBT HTS TBC with real tab stops, ED EL ECH (and DECSED/DECSEL), ICH DCH IL DL, SU SD, DECSTBM, RI, DECSC/DECRC (and CSI s/u), DECALN, alternate screen 47/1047/1048/1049, DECSET/DECRST for app cursor, origin, autowrap, cursor blink, cursor visible, mouse 9/1000/1002/1003, focus 1004, mouse encodings 1005/1006, bracketed paste 2004, DECSCUSR, DECKPAM/DECKPNM, DECSTR, RIS, DEC special graphics and UK sets in G0-G3 with SO/SI, REP, insert mode (IRM), SGR complete (flags and their resets, 16/256/truecolour, `;` and `:` forms, underline styles `4:0`-`4:5`, 21, underline colour 58/59, 90-97, 100-107), and replies DA1, DA2, DSR 5/6, DECXCPR, DECRQM (ANSI and DEC). **Skipped:** DECSLRM and left/right margins (mode 69 reports permanently reset; `CSI s` is save-cursor), DECCOLM, DECSCNM, protected areas, LNM, SS2/SS3.

**Public API added** (all class M, doc comments and inventory rows done): `TerminalEvent` (the frozen five cases, declared whole; 1.3 emits `.reply` and `.bell`, the other three wait for OSC in 1.4), `TerminalEmulator.drainEvents()`, `TerminalUnderlineStyle`, and `TerminalAttributes.underlineStyle`, `.underlineColor`, `.blink` (`underline` stays, now computed from the style). Storage is unchanged in kind: `TerminalRow` gains erase and insert/delete edits (`TerminalRow+Edit.swift`) that truncate or splice in place for plain ASCII rows and otherwise rebuild from one slot per column, merging spans; still no struct or `Character` per stored cell.

**Judgement calls (see the rulings).** Scrollback receives rows only from a full-screen scroll on the primary screen (a partial region or the alternate screen drops them, so absolute row numbers stay stable); erase and scroll fill with the pen's background; ICH/DCH/ECH/IL/DL clear the pending wrap and ED/EL do not; DECSC state is per screen; DECSTR sets autowrap on; RIS keeps scrollback; DECSCUSR 0 is the power-on steady block; replies cap at 1 024 queued events and consecutive bells coalesce.

**Tests.** 101 in `MetalUITerminalTests` (54 before): 30 new `.vtfix` fixtures (cursor movement and a DECALN field, ED 0/1/2/3, ICH/DCH, scroll regions with IL/DL/SU/SD, origin mode off and on, autowrap at the last column, tab stops set/clear/walk, DEC graphics in G0 and G1, SGR matrix and edges, background-colour erase, 1049/47/1047, save/restore, mode and cursor-style sets and resets, replies, bell, REP, region scrollback, RI, IRM), each run whole, byte at a time and cut at every position. The fixture format gained `attr`, `replies`, `events` and the modes `originMode`, `alternateScreen`, `cursorStyle`. Unit suites for regions, edits (wide cells, rendition kept, BCE, damage), save/restore and resets, replies (queue, bound, DECRQM sweep), SGR (forms, malformed, every flag) and charsets. Chunk-split invariance covers six new streams of the new sequences and now compares the region, tab stops, pen, charsets, saved cursors, the event queue and the hidden screen as well; the fuzz bytes are weighted toward the new finals and the invariants add region validity, tab-stop count, hidden-screen size, run coverage and wide-cell integrity.

**Mutations, each red** (a source line changed, the suite run, the file restored from a copy and diffed): CUU without the top margin; CUD without the bottom margin; IL not limited to the region; DECSTBM bottom off by one (traps); RI not scrolling; partial regions pushing to scrollback; the alternate screen pushing to scrollback; 1049 without the cursor restore; 1049 without the clear on entry (first run survived, `entering1049GivesABlank...` added); 1047 without the clear on exit; DEC graphics table offset by one; the colon colour-space slot ignored; CPR ignoring origin mode; erase ignoring the background; DCH not shifting; the wide-half fix-up removed; HTS ignored; TBC 3 ignored; REP once; DECRC dropping the pen; erase-to-end keeping the soft wrap; ICH not dropping the overflow; bell not queued; DA1 wrong; SGR 22 clearing bold only; DECSCUSR blink inverted; origin mode not homing; IRM ignored for wide characters; the alternate switch not a full frame; RIS clearing scrollback.

**Bench.** The gated bench from a scratch package (the full-package release test build is too slow), plain ASCII, 80-column lines with CRLF scrolling into scrollback, 64 KiB chunks, best of four, on a machine with load averages 9-17 and other builds running: **482 MB/s** (record 335 measured 521 unloaded). The proposal is 300 MB/s; the fast path is unchanged except one store of the last byte per run.

**Linux.** `MetalUITerminalTests` in `swift:6.4-noble` (separate build volume, removed after): **101 tests green** (run from a scratch package holding the target and its tests, with the fixtures, because a full-package Linux build is far slower; the macOS run is `--build-system native`, `--no-parallel`, also 101).

**Not done.** DECSLRM; OSC, titles, hyperlinks, working directory (1.4); resize and reflow (1.5); selection, search, viewport (1.6); encoders (1.7). `TerminalEvent.workingDirectory(URL)` makes the module import Foundation (Linux: Foundation is in the toolchain).
