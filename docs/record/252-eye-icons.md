# 252. Eye icons for Linux and Windows (Alloy gap G16, `SYM-P`)

Branch `feat/eye-icons`. Alloy's chat code blocks toggle with `eye.circle` / `eye.slash.circle`. They already draw as SF Symbols on macOS (untouched); this adds the four eye names to the bundled Lucide table.

- **Mapping.** `eye` -> Lucide `eye`; `eye.slash` -> Lucide `eye-off`; `eye.circle` -> synthetic `eye-circle`; `eye.slash.circle` -> synthetic `eye-off-circle`.

No runtime, table-shape or divergence change (230 covers the Lucide stand-in look). `THIRD-PARTY-NOTICES.md` needs nothing (same tarball, same licence).
