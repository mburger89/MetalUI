## 1. What was built

- **`SDLGPUShaderCompiler`** (`MetalUISDLGPU`, `SDLGPUShaderCompiler.swift`): `shared(libraryPath:)` loads libSDL3_shadercross **at run time** (`SDL_LoadObject`, never linked, `RC-B`), process-wide, once, no `Quit`, no unload; an absent library is a thrown `compilerUnavailable` listing every path tried, never a trap. `compileCompute(...)` takes HLSL, entry point and defines and answers the device driver's format (`SDLGPUShaderTarget(driver:)`: Vulkan SPIR-V, Metal MSL entry `main0`, Direct3D 12 DXIL; any other driver is `unsupportedTarget`, `RC-F`) **plus the compute reflection** (`ReflectComputeSPIRV` of the SPIR-V, always). Failures throw `compileFailed` carrying DXC's own text with file, line and column (`RC-D`); an empty compiler message is its own named error, never a silent success. `selfTest(for:)` (`async throws`, `RC-X`) loads the compiler, compiles a four-line kernel, compiles a broken one and requires diagnostics, and with a device dispatches and reads back; its report names driver, format, library path, bytes and seconds (`RC-J`). Compute only (`RC-G`); warnings stay in SDL's log (`RC-I`); no compile cache (`RC-M`).
- **Bytes initializer** (`SDLGPUShaderBlob+Bytes.swift`, `SDLGPUDevice+RuntimeCompile.swift`): a public throwing `SDLGPUShaderBlob.init(name:stage:bytes:format:entryPoint:...counts...:threadCount:)` with a public `Format` (`spirv`, `msl`, `dxil`; the raw value is the `SDL_GPUShaderFormat` bit converted explicitly) validating bytes and reflection before SDL sees them (`RC-E`), and a device form so a compiled kernel reaches `compileComputePipeline(_:)`/`makeComputePipeline(_:)` through the one existing path (stage-naming errors, `GB-G`). `SDLGPUDevice.swift` and `SDLGPUShaderLibrary.swift` are **not edited** (extensions only), so the sibling merged clean.
- **C shim** (`SDLBridge/SDLShaderCross.c`, declarations in `SDLBridge.h`, `RC-Q`): our own mirror structs of the five shadercross structs it calls (static-asserted to the sizes the probe measured: 40, 16, 32, 36), so MetalUI builds with no shadercross header; the two dependents are preloaded by full path because the install has no rpath (`RC-N`, `RC-U`); `SDL_ShaderCross_Init` once under an atomic (`RC-X`). Compiles are **not serialized** (DXC builds a compiler per call); diagnostics are read on the failing thread first.
- **Pure, portable lane** (`MetalUIShaderCompile`, no SDL trait, runs on every platform's CI): `RuntimeLibraryLocator.loadOrder` (explicit path, `METALUI_SHADERCROSS_LIB` as file or directory, beside the executable and its `../lib`, the `METALUI_SHADERCROSS` executable's sibling `lib`, the loader path; an explicit path or variable naming a missing file is an error, not a fall-through, `RC-C`) and `ComputeBlobValidation` (magic, whole words, thread axes >= 1 with x*y*z <= 1024, every count in 0...64 as a sanity bound).
- **Packaging** (`docs/packaging.md` §4a, `THIRD-PARTY-NOTICES.md`, `RC-K`): four files per platform in one directory the locator finds (shadercross, dxcompiler, spirv-cross, dxil), about 32 MB (macOS) to 39 MB (Linux aarch64); licences zlib, LLVM/NCSA (DXC), Apache-2.0 (SPIRV-Cross, SPIRV-Tools), Khronos MIT-style (SPIRV-Headers), recorded as an optional, not vendored, not published section.

## 5. Measurements (dated 2026-10-22, never pinned; pins count work)

Generated kernels, median of 3 (`runtime-compile-measure.sh`). **Linux aarch64 image, idle:** 200 lines 0.056 s to SPIR-V, 0.005 s to MSL, 0.085 s to DXIL; 1000 lines 0.564 / 0.021 / 0.679 s; 2000 lines 2.658 / 0.057 / 2.904 s; first compile 0.056 s, library load 7 ms. **macOS arm64** (probe, idle): 0.044 / 0.421 / 1.372 s to SPIR-V, 0.004 / 0.019 / 0.043 s SPIR-V to MSL; under load 265-470 (an upper bound) 0.081 / 0.441 / 1.588 s, first compile 0.081 s, load 0.146 s. DXC's HLSL-to-SPIR-V is more than 95 % of a Metal-route compile and grows faster than linearly (2000 lines is about 4.7 times the 1000-line kernel); a 1000-line kernel is about half a second, so compile off the main actor and cache in the app. Self test, whole test: macOS Metal 0.039 s, Linux lavapipe 0.052 s. A local shadercross build of the pin took about 25 minutes of wall clock on a loaded Mac (8 min 30 s idle, `docs/packaging.md` §4a); the first Linux image build stopped at step 1115 of 1304 with `No space left on device` and the resumed build finished.

## 7. Hazards

An app's SDL3 and shadercross's must be one instance for `SDL_GetError` to carry DXC's text (`RC-D`; the self test checks it). The install has no rpath, so the locator preloads dependents by full path (`RC-N`). `package` symbols are invisible to the `MetalUISDL` tests, so the seam is `internal` (`RC-X`). A parallel whole-suite `Backends/SDL` run on macOS hung in the sibling item's record (§150); `--no-parallel` is the rule. The compile is seconds for a large kernel: never on the main actor.
