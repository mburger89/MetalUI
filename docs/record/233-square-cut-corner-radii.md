# 233. A square clip cutting a rounded one (CM-J)

Renumbered from 230 on merge: record 230 is `230-symbol-images.md` (merged first), and 231/232 are held by in-flight branches.

MetalCreator (b0fa5ae5) saw masked groups for node views: `background(in: RoundedRectangle).clipShape(RoundedRectangle)` inside a canvas under a square `.clipped()` viewport. Headless reproduction: a node wholly inside the viewport makes 0 groups, at scale 1 and 2, plain, under `.offset`, under `scaleEffect`, in a `ScrollView`; a node **straddling** the viewport edge (square outer clip, rounded inner clip, the cut through the node) made 3 masked groups for a 3-leaf node (MetalCreator: 7, one per clipped leaf), at every scale and with or without `scaleEffect`. Not the continuous corners of #224 (`.circular` changed nothing).

Cause: #216 (`CM-B`, `53a1c843`): `intersectReportingCrossing`'s last fallback returned zero radii and `crosses = !(square && square)`, and `boxReachesACornerCut` is true for the node's *kept* rounded corners, so a flattening-entry `cutToEntryClip` (and `paintClipped`) opened a masked group. The group was not needed: the intersection of an axis-aligned square clip with a rounded rect is the box with the rounded rect's radii on the corners the cut leaves alone, which the per-primitive rounded mask expresses.

Fix (`CM-J`): `Frame.boxCornerRadii`; the fallback returns it with `crosses = false` for a square-vs-rounded pair. A cut through a corner zone, and two rounded clips, still take the mask. Tests (`ClipMaskTests` 23): the straddle makes 0 groups with round kept corners and a square cut side (pixels), with and without a flattening scale; a cut through a zone still groups; the `intersect`/`clipsCross` values. Group count for the straddling test node: 3 before, 0 after. The bracket-drag fixture (MetalCreator-shaped) goes 174 -> 180 rects and 437 -> 516 glyphs in the root scene (pre-#216: 182, 550): the nodes whose cut passes through a corner zone keep their group. Where the mask is still needed it is one group per contiguous run of leaves sharing the scope's crossing token, as before.
