## 5. What the plan did not say, and where this differs

- **`EitherGroup` needed no flag.** The plan sets a flag at the `buildEither` sites; `EitherGroup` is an enum made only by the builders (the grep found no direct construction), so every branch is a unit. A hand-written `.first(_)` fades too. `OptionalGroup` is the one with a flag (`init(builder:)`), because the framework builds it by hand.
- **`RetainLog.Marks` was not extended.** The recorder keeps the ranges' start index and the scene sequence where its window opened (`SubtreeRecorder`), so the count rides the recorder, not the log.
- **A suspended scope, not a removed one.** The plan removed the unit's `.fade` scope from `paintScopes` around an annotated member; the scope is flagged `suspended` and `processScopes` skips it, so no index or recorder height moves.
- **The carve of a handoff runs only when a flight starts** (`start != target`): a handoff whose start equals its target is an ordinary cross-fade in place, which is SwiftUI's answer for a pair that does not move.
- **`MB2d` and `MB2k` are spelled differently from the plan.** The unit is one fade, not per-member, so "first member only" is the removal slice cut to its first primitive; `buildActivity` never sees a paint-time range, so the retained mutation counts the produced notes as build activity (a graft window that notes a unit is refused).
- **The kept scene is retained only while a unit painted.** A tree with no builder conditional keeps nothing.
- **A ghost's key position is the unit**, so `XF-F`'s anchor walk (the key's grandparent chain) starts at the unit's parent; no change to B1's code.
- **`MB2n` is green and reported, not fixed** (section 4): the `.fade` taint is a third guard behind `noteActiveAnimation()` and `requestAnotherFrame()`, each of which taints the open recorders by name (`activeAnimation`, `requestAnotherFrame`). Kept: it costs one comparison, only evaluated with a recorder open, and it is the guard that stands if a later change stops calling either. Decision on review: keep the taint and keep `MB2n` as a known green mutant.
- **Unmeasured, stated:** the look in a real window (group `XF`); a ghost frozen at its last place while the fade runs; a `Deferred`, a glass container or a `.compositingGroup()` inside a unit; a ghost drawn into the range of another unit (a nested container's ghost inside a fading unit is sliced into that unit's own ghost); the timing of `XF5b` (predicted by analogy to `X7`, pinned).
