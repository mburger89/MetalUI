# The terminal (`TRM-`)

Rulings: `docs/superpowers/2026-11-16-terminal-decisions.md`; frozen and draft signatures: `docs/superpowers/specs/2026-11-16-terminal-design.md`; record 334 (Phase 0). One or two sentences per rule; detail lives in the record of the PR that landed it.

**Module split** (`TRM-A`). `MetalUITerminal` (emulator, encoders, `PseudoTerminal`, `TerminalSnapshotSource`) is UI-free and imports nothing from MetalUI, AppKit, Metal or SDL; `TerminalView` lives in `MetalUITerminalUI`. No MetalUI product depends on either, and the parser is written in-house with no third-party code read or copied.

**Freeze** (`TRM-B`). Gaps 1, 3 and 4 are frozen by record 334 and change only by a new `TRM-` ruling Alloy accepts; gaps 2 (`TerminalView`, `TerminalPalette`) and 5 (`SurfaceRedrawTrigger`) are draft until the start of Phase 5.

**Replies** (`TRM-C`). A `TerminalEvent.reply` MUST be written to the pty by the owner; a host that drops it breaks vim and less. `TerminalPalette.boldIsBright` defaults to false and bold is the bold face only; the blink idle stop is a view flag.

**Key capture** (`TRM-D`). A capture layer hears a key before every other stage, `except` shortcuts skip it, and a key answered `.ignored` (including every key that encodes to nothing) goes through the unchanged pipeline from its first stage. Option-as-meta covers both Option keys and bypasses dead keys while on; nothing is captured while marked text composes.

**Key capture, built** (`TRM-U`..`TRM-Y`, record 338). `keyCapture(except:optionAsMeta:)` marks the keyboard layer of the `onKeyPress` handlers it sits with (a marker handler on `KeyboardAttachment.capture`, not a `Handlers` member); `Window.dispatchKeyCapture` is the first key stage and offers the key once, outermost layer first; `except` and marked text skip it; `PlatformWindow.setRawOptionKeys(_:)` follows focus and bypasses `inputContext` for Option on AppKit (Alt on SDL).

**Platforms** (`TRM-E`). Windows 10 1809+ and Linux 5.3+ (pidfd); the Windows default shell is `pwsh` else `powershell`; on Windows `.interrupt` writes 0x03 and the other signals terminate the job object, and there is no foreground group.

**Storage** (`TRM-F`). A row is UTF-8 text plus run-length attribute spans, copy-on-write, never a struct or `Character` per cell; scrollback is a ring of compacted rows, and a 10 000 x 120 ASCII scrollback is proved under 4 MB by a counted byte census.

**Parser** (`TRM-G`). UTF-8 is decoded first (U+FFFD per maximal invalid subpart, the breaking byte decoded afresh), C1 controls are the scalars U+0080-U+009F, string payloads are capped in bytes and an overlong one is dropped to its terminator, and any split of a stream gives the same state.

**Phase 1.2 seam** (`TRM-H`). The emulator prints, wraps and moves the cursor and records mode flags; every other sequence is parsed and dropped until its phase, so no declared behaviour is a stub. Fixtures are `Tests/MetalUITerminalTests/Fixtures/*.vtfix` (`TRM-I`); the parser guards are chunk invariance, seeded fuzz, the census and the gated bench (`TRM-J`).

**POSIX pty** (`TRM-K`..`TRM-O`). `PseudoTerminal` starts its child with `posix_spawn` and `POSIX_SPAWN_SETSID` (the child's own first open of the slave gives it the controlling tty; the C `fork` path stays for glibc below 2.34 and tests run both), with exactly fds 0-2, every signal at default, and the size set before the child exists through a slave the parent holds open (Darwin forgets a size set on an unopened pty).

**Pty I/O** (`TRM-M`, `TRM-N`). `read` is >0, 0 would block or -1 end of file (a 0-byte read, EIO, or after `close`), latched so the level-triggered source stops firing; `write` queues on an internal queue, never blocks, never drops, never reorders.

**Pty lifetime** (`TRM-O`). No SIGCHLD handler: macOS process source, Linux pidfd (shared poll fallback); one reap under the lock that `signalGroup` takes, so a reaped pid is never signalled; `close()` stops callbacks, not reaping.

**Windows ConPTY** (`TRM-AX`, `TRM-AY`, record 350). `PseudoTerminal` on Windows is a C engine over overlapped named pipes, one thread-pool IO per direction (no thread per pty), the child suspended into a kill-on-close job and then resumed, an exit wait, `.interrupt` as `0x03` and every other signal as `TerminateJobObject` (`.exited(1)`); the stream ends only because the exit starts `ClosePseudoConsole` on a short-lived thread while reading goes on, and `close()` does the same with the output discarded, so it cannot deadlock. The command line is quoted by `CommandLineToArgvW` rules, the environment block is sorted UTF-16, and Windows tests assert on the emulated screen, never raw bytes.

**Phase 1.3 screen** (`TRM-Z`..`TRM-AD`). The emulator executes cursor motion within margins and origin mode, erase with background colour, insert/delete, scroll regions, tab stops, DECSC/DECRC per screen, the alternate screen (47/1047/1049), DECSTR/RIS, DEC graphics, REP, SGR in `;` and `:` forms and the DA/DSR/CPR/DECRQM replies; DECSLRM is skipped. Rows reach scrollback only from a full-screen scroll on the primary screen; every reply is a `TerminalEvent.reply` from `drainEvents()` that the owner MUST write, and only `.reply` and `.bell` are emitted before OSC (1.4).

**Phase 1.4 OSC and snapshot source** (`TRM-AE`..`TRM-AH`, record 341). OSC 0/2 give `.title` (256 characters), OSC 7 a `.workingDirectory` for a `file` URL on a local host only, OSC 8 a link id in the pen (kept over SGR 0, reused by `id=` plus target, `TerminalSnapshot.links`), OSC 10/11 queries answer only when the owner set `queryColors`; OSC 52 and the rest are dropped. `TerminalSnapshotSource` publishes and merges on every feed, wakes the bound view once until `takeSnapshot()`, sends `.reply` to `onReply` on the queue and everything else to `onEvents` in one main-actor batch per hop.

**Phase 1.5 resize and reflow** (`TRM-AM`..`TRM-AP`, record 345). `resize(cols:rows:)` clamps to 2 x 1, is a no-op at the same size and publishes a full frame; the primary screen and its scrollback rewrap by the soft-wrap flag (a wide character never splits, trailing default blanks are not carried, the cursor stays on its character), the alternate screen clips; growing pulls rows back from scrollback, shrinking drops blank rows then pushes the top to scrollback and never moves the cursor off the screen; the region resets, tab stops keep their columns, a wrapped row keeps its trailing blanks in `compact()`. **The oldest retained row keeps its absolute number**, `firstRow` moves only by evictions, a width change renumbers and bumps `reflowGeneration` (a position is valid for one generation, a height-only resize keeps all of them).

**Phase 1.6 selection, search and viewport** (`TRM-AQ`..`TRM-AT`, record 347). `selection` (`.linear` or `.block`, absolute rows) is cleared by a later `reflowGeneration`, by the alternate-screen switch and by output that changes the selected columns of a screen row (xterm), and is clipped, then cleared, when scrollback evicts its rows; `selectedText()` joins soft-wrapped rows with no separator, trims trailing blanks per row and takes a wide character once; `search` is case-sensitive, spans wraps, never wraps around and matches whole cells only; `scrollViewport(toOffset:)` clamps, publishes a full frame and keeps the same rows in view as output scrolls; `wordRange` and `lineRange` are the package boundaries for Phase 5 gestures (word characters letters, digits and `_-.~/:`).

**Cost.** A terminal output, blink or selection frame costs 0 builds and 0 element requests, and a hidden or idle terminal schedules nothing; every shared-view change pins the steady-frame request counts for apps that do not use it.

**Tests.** Pty and parser tests bound every wait and never sleep for timing; each guard is shown red against the wrong routing first (`docs/practices/verifying-tests-can-fail.md`).

**Surface-only redraw** (`TRM-P`..`TRM-T`, record 337; gap 5, draft until Phase 5). `SurfaceRedrawTrigger.requestRedraw()` redraws one `GPUSurface` in a frame with no build: `Window.drawFrameIfNeeded` re-encodes `lastScene` and hands the renderer only the pending surfaces' requests (`SurfaceDrawRequest.isForced`), and a full frame forces the same requests whenever the window is dirty, animating, on a timer or the scale, size or atlas `layoutGeneration` moved. A trigger whose surface the last frame did not paint is a no-op (unbound), `requestRedraw(after:)` keeps the earliest deadline per surface on the frame clock. A change to shared view paths pins an untriggered surface's steady-frame numbers (`SurfaceOnlyRedrawTests`).

**Encoders** (`TRM-AI`..`TRM-AL`, record 342). `TerminalEncoder` is four pure statics over `TerminalModes`; a Command key encodes to `[]`, Option is the xterm Alt parameter on special keys and an ESC prefix on the unmodified character only with `optionAsMeta`, and every key table row, mouse mode and the legacy 223 limit is a test row that fails when one byte moves. Paste strips every C0 but tab, LF and CR; keypad keys carry `isKeypad` and send `SS3` finals under `applicationKeypad`, and `wheelLeft`/`wheelRight` are buttons 66 and 67 (Alloy amendments, 2026-11-16).

**Grid sink** (`TRM-AU`..`TRM-AW`, record 348). A terminal surface draws through `SurfaceTextSink.fillRect` (a rect is a glyph instance over the solid atlas slot, sampled by its inner square so edges never bleed) and `append`; a row redraw on the retained target records an opaque background first, and a new or resized target is redrawn whole.

**Cell glyphs** (`TRM-AZ`, record 351; `MetalUITerminalUI`, `package`). A cell is whole device pixels measured once at the scale (width the advance of "M", height the line height, both rounded to nearest); a grapheme is shaped once per `(cluster, bold, italic)` through the text system's fallback and cached until the atlas `layoutGeneration` moves, so a warm ASCII screen shapes, packs and allocates nothing; box, block, braille and Powerline glyphs are synthesised to the cell (rects through the grid sink where exact, cell-sized R8 bitmaps for arcs and slants) with light strokes of `max(1, round(cellWidth / 8))` pixels so neighbours meet seamlessly; bold is the bold face only unless `boldIsBright`, and a row records its merged opaque backgrounds, then glyphs, then decorations.

**The view** (`TRM-BA`, record 357; gap 2 frozen). `TerminalView` (`MetalUITerminalUI`) reports a grid of whole cells through `onGeometryChange` (first layout, then real changes; `snapshotSource.resize` before `onResize`); output is a surface-only frame that redraws only damaged rows plus the cursor's and selection's rows, and every row on a new target or a palette, font, scale, size or reflow change; the cursor is hollow unfocused, blinks at 500 ms only for a blinking style, and stops 30 s after the last activity.

**Surface replay** (`TRM-BB`, record 359). An `.equatable()` ancestor of a `GPUSurface` replays its paint: the record keeps the surface's draw request and trigger and re-appends them (at the frame's timestamp) with the quad, so an unrelated keystroke frame pays no terminal element request and a trigger frame still draws; a value change is the component's equality and misses.

**Input** (`TRM-BC`, record 361). `TerminalView` is a key capture layer while focused and encodes each `KeyPress` through `TerminalEncoder.encodeKey(_:modes:optionAsMeta:)` with the newest modes (a key that encodes to nothing answers `.ignored`, so ⌘-keys reach menus; excepted keys and keys while composing are left alone); committed text (input method, dead keys, emoji picker, typed characters) goes UTF-8 to `onInput` once, marked text is drawn underlined in the cursor's cells and sent only on commit, and the input method's area is the cursor cell, following output on a surface-only frame. Paste is ⌘V and Edit > Paste on Apple platforms, Ctrl+Shift+V elsewhere (Ctrl+V is the child's); focus in and out is `ESC [ I`/`O` under mode 1004; every byte sent restarts the blink's idle clock. The wiring is fields of the one keyboard layer: a keystroke frame costs the view's 2 requests, output after it 0.

**Pointer** (`TRM-BD`, record 362). `TerminalView` reports presses, moves and releases through `encodeMouse` while the program has mouse reporting on (⇧ at the press bypasses it, also for the wheel); the wheel is reports, else arrow keys on the alternate screen (Terminal.app's alternate scroll, not xterm's default), else scrollback (3 rows a wheel line, trackpad points accumulated); local selection is drag (linear), ⌥-drag (block), double (word), triple (line), ⇧-click (extend), auto-scrolling past the edge, copied by ⌘C / Ctrl+Shift+C; ⌘ (Ctrl off Apple) hover asks `onLink` once per cell change with `.exit` on leaving, OSC 8 runs are the fallback target, a target underlines and shows the pointing hand. The wiring is fields of the keyboard layer (`pointerInput`, a `styleProvider` for the pointing hand): a rebuilt frame of a focused view stays 2 requests, an editor keystroke beside an idle one 2 (the public view is retained by default, `.equatable()` over an internal field), entering a link costs no build, and a drag event is one build, not surface-only. `TerminalView` is `Equatable` over its inputs (closures excluded) and retains by default.
